# Linux notes

## Linux Upskill Day 1: get to know your server (9 Nov 2026)
Machine: OrbStack, Ubuntu 26.04.1 LTS, log in with `ssh learn@orb`

- `cat /etc/os-release`: general info about the ubuntu version and other informations
- `uptime`: running time of the vm
- `whoami`: shows which user you’re logged in
- `free -h`: ram usuage
- `df -h`: shows disk space
- `ip address`: ip address of the vm
